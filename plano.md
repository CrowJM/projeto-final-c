- `verificarVitoria()` -> verificar se todos os pares foram encontrados


- **Matrizes** -> guardar o tabuleiro
- **Funções** -> separar cada parte do jogo
- **if / else** -> verificar se as duas cartas são iguais
- **while** -> continuar o jogo enquanto ainda existirem pares
- **for** -> mostrar e percorrer o tabuleiro
- **strings** -> guardar o nome do jogador
- **recursão** -> pensar numa forma simples de usar mais tarde
